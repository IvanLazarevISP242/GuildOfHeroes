## Собственный проект

Тема проекта: музыкальная библиотека альбомов Viperr
Главный класс: Album
Почему этот объект нужен программе: он хранит в себе все данные
Какие данные хранит объект:
- название альбома
- авторы
- год
- список песен

Все данные задаются через конструктор
